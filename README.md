# Wedding invitation website

A responsive, static wedding invitation built with HTML, CSS, vanilla JavaScript, and Bootstrap 5. It has no backend and can be published with GitHub Pages. Its animations include an opening invitation, a touch-friendly scratch-to-reveal date card, and gentle section reveals while scrolling.

## Personalize it

Edit `index.html` to update the couple's names, family names, event dates and times, venue, map links, description, and image URLs. Update the wedding date in `script.js` so the countdown matches. Add an MP3 URL to the `<source>` element in `index.html` to enable the music button.

Images and fonts currently load from Unsplash and Google Fonts; Bootstrap loads from jsDelivr. For a fully self-contained deployment, download and store those assets locally and update their URLs.

## Publish with GitHub Pages

Commit `index.html`, `styles.css`, `script.js`, and this README to your repository. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select your branch and `/ (root)` folder, and save. The site is plain static files, so no build command is needed.
